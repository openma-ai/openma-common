# Common v0.11.0

Released through the immutable Git tag `v0.11.0`. The tag runs
`release-tag.yml`, which publishes `@openma/common@0.11.0` to npm with trusted
publishing and provenance.

## Changes

Minor over `v0.10.0` (`ddd3b3c`). Adds one subpath; no existing export
changes.

### Telemetry (`@openma/common/telemetry`)

- New subpath built on `@opentelemetry/api` only. `@opentelemetry/api`
  `^1.9.0` is an optional peer dependency: hosts that never import the
  subpath do not need it. The SDK pipeline (tracer provider, processors,
  exporter) stays in the host.
- `AcpTraceObserver` reads outgoing session events by `type` and records
  GenAI semantic-convention spans:
  - `create_agent` from session start to ready or start error. Re-acking an
    already ready session does not open another one.
  - `invoke_agent` per turn, opened on `session.prompt_accepted` (a queued
    prompt does not start a turn) and closed with its finish reason.
  - `execute_tool` per tool call under its turn.
- `linkTurn(sessionId, turnId, traceparent)` parents the next turn on a W3C
  `traceparent`, so a GUI action and the agent turn it caused share one
  trace. An unsampled parent (flags `00`) leaves the turn unrecorded under a
  parent-based sampler.
- Spans carry ids, names, kinds, counts and closed `error.type` codes only.
  `gen_ai.tool.name` comes from `_meta.claudeCode.toolName`, else the ACP tool
  kind, never the tool title (titles include paths and commands). Error
  messages never enter span status.
- `resolveTelemetryExport({ enableKey, env, settings })` resolves OTLP trace
  export from a host master switch plus the standard `OTEL_*` variables. A
  settings table takes precedence over the environment, and an empty value
  there unsets the variable. `parseOtlpHeaders`, `OTEL_TRACE_KEYS` and
  `OTEL_SECRET_KEYS` support hosts that store or redact these values.
- `formatTraceparent` / `parseTraceparent` / `traceparentOf`, the `GEN_AI`
  attribute table and `summarizeSpan` (a finished span as one plain record
  for local logs).

This release commit bumps `package.json`, the install pin in `README.md`, and
adds these notes.
