# Common v0.14.0

Minor release over v0.13.1, delivered through the immutable v0.14.0 tag and
release-tag.yml with trusted publishing and provenance.

## Changes

- #65 — Portable runtime input admission, acknowledged dispatch and preterminal
  finalization hooks. Hosts can fence consumption, await real activity drain,
  save native state and confirm terminal publication without putting cloud
  Work/SQL dependencies into the local harness.
- Same-root steer continuation with FIFO admission and cancellation-safe
  completion. A correction does not create a phantom model span or replace
  the original permission callback owner.
- Exact advertised native permission mapping for supported Claude and Codex
  ACP adapter versions; unknown, rejected and ambiguous mode changes fail closed.
- Local runtime restart and isolation tests retain public-entry coverage,
  including independent Node processes and credential-free execution.
- #62 — Verified candidate/package pipeline and immutable artifact publication.
- #63 — Shared Managed tool confirmation controls (previously shipped in 0.13.1).
- #64 — Previous 0.13.1 version baseline; no published artifact is overwritten.

## Validation and limitations

Release requires Linux verification, Windows verification, interactive surface,
patch coverage, package consumer smoke and production approval. ACP fixtures
exercise real protocol transport but do not certify live model/provider behavior.
Downstream deployment certification remains the responsibility of consumers.

Use @openma/common@^0.14.0 or github:openma-ai/openma-common#v0.14.0 after publication.
