# Common v0.7.8

Patch over `v0.7.7`. No exports were removed or renamed.

## Changes

- Transcript disclosure rows (`activity-disclosure-row` with
  `chat-interactive-surface--transcript`) drop leading inline padding so process
  / tool summary text and icons align with assistant body copy.
- Hover on transcript rows is **color-only** (muted → foreground, icons and
  chevrons follow); no full-row background wash. Rest stays transparent,
  expanded-without-hover stays plain, and `:focus-visible` keeps the shared
  focus ring on `chat-interactive-surface`.
- Tool / activity summary disclosure triggers stay native `<button type="button">`
  controls with `tabIndex={0}`, shared `data-chat-turn-disclosure-trigger`
  (alongside process rows), `aria-controls`, and Enter/Space toggling. Activity
  group headers render outside the inert process body so keyboard Tab can reach
  them while the process strip is expanded.
- Transcript hover text uses `:is()` selectors (including
  `.chat-transcript-disclosure-summary` and host utilities like `.text-fg-muted`
  / `.turn-muted`) so summary copy and icons deepen on hover, not only the
  chevron.

This release commit bumps `package.json`, the Git install pin in `README.md`,
and these notes.
