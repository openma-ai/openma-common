# Common v0.7.5

Released through the immutable Git tag `v0.7.5`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

Patch over `v0.7.4` (`d09ed76`). No exports were removed or renamed.

- #21 (`7f58a34`) adds `@openma/common/project-ui` and
  `@openma/common/project-ui/styles.css`, a shared Projects surface for hosts
  that inject a `ProjectClient`. The client exposes `list()`, `view()`,
  `save()`, `saveWork()`, `submit()`, `goal()`, and `delete()`, with optional
  `pickFolders()`, worktree helpers (`listWorktrees()`, `createWorktree()`,
  `deleteWorktree()`), and `subscribe()` for store updates. The entry exports
  React components (`ProjectsPage`, `ProjectEditor`, `ProjectConversation`,
  `ProjectComposer`, `ProjectMessageAttachments`, `CreateProjectDialog`,
  `ProjectFolderList`, `ProjectSettings`), hooks (`useProjects`, `useProjectView`),
  goal helpers, and the `ProjectClient` types. `dist/` was updated in that
  commit.

This release commit only bumps `package.json`, the Git install pin in
`README.md`, and these notes. It does not publish to npm or move an existing
tag.

Consumer manifests and remote branches were not changed. This package release
does not certify or publish any consumer application's installer.
