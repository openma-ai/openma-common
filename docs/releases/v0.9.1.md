# Common v0.9.1

Released through the immutable Git tag `v0.9.1`. This is the first release
published to npm by CI: the `v0.9.1` tag runs `release-tag.yml`, which
publishes `@openma/common@0.9.1` with npm trusted publishing and provenance.
`0.9.0` was published to npm manually as the bootstrap.

## Changes

Patch over `v0.9.0` (`ee400c3`). No exports were added or removed.

- #48 (`9c68d9a`) — `@openma/common/acp-runtime` no longer pulls in
  `node:child_process`:
  - `probe.ts` imported `NodeSpawner` statically, and the `acp-runtime` index
    re-exports `probe`, so every importer of the entry loaded
    `node:child_process`. Hosts without child processes, such as Cloudflare
    Workers, failed to load the module.
  - `NodeSpawner` is now loaded on first use when no spawner is passed.
    Callers that pass a spawner never load it.
  - A test walks the entry's static import graph and fails if a Node-only
    module is reachable.
- #47 (`f5e21c0`) — release tags publish to npm: `private` is dropped,
  `publishConfig` sets public access and provenance, and `release-tag.yml`
  gains a `publish` job (GitHub OIDC, no token, `production` environment,
  idempotent for versions already on npm). README and CONTRIBUTING describe
  the npm install and the release flow.
- #42 (`3202df7`) — CI only: fast checks on pull requests, heavy suites after
  merge. No source or export changes.

This release commit only bumps `package.json`, the install pins in
`README.md`, and these notes.

Consumer manifests and remote branches were not changed.
