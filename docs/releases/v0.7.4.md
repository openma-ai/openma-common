# Common v0.7.4

Released through the immutable Git tag `v0.7.4`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

Patch over `v0.7.3` (`4dc29cd`). No exports were removed or renamed.

- #19 (`a58916b`) adds `@openma/common/acp-fork`, a browser-safe client entry
  for inclusive ACP message fork. It exports `forkSupport()`,
  `acpForkPointsFromMessages()`, `acpInclusiveForkCapabilityMeta()`, and the
  `ACP_INCLUSIVE_FORK_CAPABILITY` constant with no `node:` imports.
  `@openma/common/acp-runtime` keeps `acpForkRequestMeta` (`node:crypto`) and
  re-exports the client helpers. CI adds a browser bundle check for the new
  export. `dist/` was updated in that commit.
- #20 (`5a3f48c`) adds shared harness catalog, installer, and agent-setup
  services vendored from Backchat. `@openma/common/acp-harnesses/registry`
  merges the official ACP registry with a static overlay and exposes
  `loadRegistry()`, `detect()`, and `detectAll()`.
  `@openma/common/acp-harnesses/installer` installs registry agents and managed
  adapters via `installAcpRegistryAgent()`, `listAcpRegistryCatalog()`, and
  related uninstall/repair helpers.
  `@openma/common/acp-harnesses/agent-setup` provides
  `createAcpAgentSetupService()` for warmup, install/upgrade/uninstall,
  authentication, and capability inspection. `acp-runtime/probe` gains
  `probeAgentSessionConfig` for setup inspection. `dist/` was updated in that
  commit.

This release commit only bumps `package.json`, the Git install pin in
`README.md`, and these notes. It does not publish to npm or move an existing
tag.

Consumer manifests and remote branches were not changed. This package release
does not certify or publish any consumer application's installer.
