# Common v0.7.3

Released through the immutable Git tag `v0.7.3`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

Patch over `v0.7.2` (`b3ddd9f`). No exports were removed or renamed.

- #13 (`7778d16`) adds two decoders. `@openma/common/protocol/openai-agents`
  decodes OpenAI Agents items, turns, and session stream events into OpenMA
  events, matching backchat `direct-agent-runtime` at `64fd74d`.
  `@openma/common/protocol/cursor-cloud` decodes Cursor Cloud Agents API v1
  run SSE events into OpenMA events. Canonical event types are unchanged.
  `dist/` for both exports was updated in that commit.
- #14 (`643df32`) checks the Cursor Cloud decoder against the live Cloud Agents
  API. `interaction_update` `user-message-appended` maps to `user.message`. A
  stream that closes as `stream_unavailable` reconnects, and that transport
  code stays a vendor event instead of `session.error`. The live test runs
  from the separate `.github/workflows/cursor-cloud-live.yml` workflow behind
  `CURSOR_API_KEY`, so ordinary required checks do not depend on it.
  `dist/` was updated in that commit.
- #16 (`8cf6cd4`) fixes #15. `NodeSpawner` no longer installs `SIGHUP`,
  `SIGINT`, or `SIGTERM` listeners in the Electron main process
  (`process.versions.electron` set and `process.type === "browser"`).
  Electron's native handlers stay in place, so the host's quit flow runs, and
  agent children are reaped from the `exit` hook when the process actually
  quits. A pure Node process with no other listener for that signal still
  cleans up children and re-raises the signal. A host with its own listener
  keeps it and is not re-raised. `dist/` was updated in that commit.

This release commit only bumps `package.json`, the Git install pin in
`README.md`, and these notes. It does not publish to npm or move an existing
tag.

Consumer manifests and remote branches were not changed. This package release
does not certify or publish any consumer application's installer.
