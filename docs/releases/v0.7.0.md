# Common v0.7.0

Released through the immutable Git tag `v0.7.0`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

New ACP runtime APIs, all optional for existing callers:

- `sessionConfigOptionsFromResponse()` turns a legacy `models` catalog into a
  model select when the agent did not already send a model config option.
- `AcpSession.legacyModels` keeps that catalog after the ACP SDK drops unknown
  response fields. The runtime does not rewrite the wire bytes.
- `SessionOptions.clientCapabilityOverlay` deep-merges host capabilities into
  `initialize`. `fs` and `session.configOptions` merge one level. `auth._meta`
  and top-level `_meta` merge key by key, and the overlay wins.
- `probeAgentAuthStatus()` reports `configured`, `needs-auth`, `none`, or
  `unknown`, including `agent`, `terminal`, and `env_var` methods.
- `authenticateAgent()` returns `completed` or `started`. Gateway and api-key
  values are sent as authenticate `_meta`. Terminal and `terminal-auth` flows
  are handed to the host. A still-pending agent login can stay alive until it
  finishes or the background timeout (default 10 minutes) elapses.
- `acpForkRequestMeta()` builds `jetbrains.air.fork` v1. The fingerprint is
  `sha256:` plus the SHA-256 of the message text's UTF-8 bytes.
- `isAuthenticationRequiredError()` matches JSON-RPC `-32000` whose message
  starts with `Authentication required`. `isAuthRequired()` stays code-only.

Behaviour fixes:

- On POSIX, `NodeSpawner` starts the agent in its own process group, signals
  that group on `kill` and on host `exit` / `SIGHUP` / `SIGINT` / `SIGTERM`,
  and escalates `kill()` to `SIGKILL` after 2 seconds. Windows still kills the
  direct child.
- `session/new`, `session/load`, and `session/resume` retry once after
  `Authentication required`, using the first method whose type is `agent`
  (a missing type counts as `agent`). `session/fork` is not retried.
- When `perTurnTimeoutMs` fires and the agent ignores `session/cancel`, the
  prompt iterator ends with `Error: ACP prompt timed out after ${ms}ms`.
- Concurrent `dispose()` calls share one promise and wait for `session/close`
  and the child kill.

## Validation (2026-10-02)

- Common: `pnpm typecheck` and `pnpm build` pass on this release commit. A
  second build does not change `dist/`. The full Vitest run after installing
  `uv` 0.12.22 is 506 passed and 1 failed (507). The failure is
  `tests/acp-distributions.test.ts` "uses the sandbox CA bundle for uvx HTTPS
  without disabling certificate verification": `uv` 0.12.22 rejects the
  fixture certificate with `CaUsedAsEndEntity`. It is not caused by this
  release. The other three uvx cases that previously failed with `spawn uv
  ENOENT` pass once `uv` is installed.
- Clash PR #15, checked locally against the pre-tag tree and not pushed:
  `@clash/local-api` typecheck passes, and the ACP, Codex model-fallback, and
  session-lifecycle tests pass (79). The thin runtime, node spawner, and
  legacy-model adapters can be deleted in favour of these exports.
  `probeAgentSessionConfig` remains in Clash.

Consumer manifests and remote branches were not changed. This package release
does not certify or publish any consumer application's installer.
