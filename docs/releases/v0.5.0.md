# Common v0.5.0

Released through the immutable Git tag `v0.5.0`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

- Shared chat rendering, virtual scrolling and nested disclosure persistence.
- Shared composer drafts, density controls, frame spacing and session controls.
- Reusable model/mode/configuration controls, permission menus and runtime status.
- ACP harness catalog and probe exports used by existing desktop consumers.
- Includes the previously merged Agent UI replay, session orchestration,
  local/managed runtime and immutable ACP artifact APIs since v0.4.0.
- Backchat website tokens remain an optional, explicitly imported stylesheet;
  importing chat UI does not install that website theme into a consumer.

The release preserves the existing reasoning trigger's serialized attribute order
while adding the styling hook. All exports include generated declarations and
runtime files. A duplicate session-orchestrator manifest key was removed.
