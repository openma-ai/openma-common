# Common v0.7.7

Released through the immutable Git tag `v0.7.7`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

Patch over `v0.7.6` (`77bcbdf`). No exports were removed or renamed.

- Introduce `chat-interactive-surface` tokens and variants (`--transcript`,
  `--control`, `--chip`) so transcript disclosure rows, session menus/chips, and
  reasoning triggers share one focus/hover/open contract: transparent at rest,
  ~8% foreground hover wash on transcript rows, control-hover on menus/chips,
  focus ring only on `:focus-visible`, and no “stuck” highlight when
  `aria-expanded` / `details[open]` without hover.
- Wire activity/tool group headers, thought rows, `ChatReasoningTrigger`, and
  session-ui menu/chip/history controls through the shared surface classes.

This release commit bumps `package.json`, the Git install pin in `README.md`,
and these notes.
