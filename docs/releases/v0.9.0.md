# Common v0.9.0

Released through the immutable Git tag `v0.9.0`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

Minor over `v0.8.0` (`fc9c958`). No exports were removed; everything is the new
additive module below.

- #38 (`b6343b1`) — shared custom ACP agent store under `~/.oma`:
  - New `@openma/common/acp-harnesses/custom-agents` module: reading,
    validating, and writing custom ACP agent definitions that Backchat and
    Martty share.
  - The single shared store is `~/.oma/config.toml` `[[agents]]` — Backchat's
    per-agent override format (`id`, `enabled`, `env` pairs, plus
    `command_override` / `args_override` / `label_override` for custom
    agents). Definitions surface in the canonical shape
    `{id, label, command, args, env}` plus the store's `enabled` flag so a
    disabled agent stays disabled.
  - Martty's legacy `~/.oma/settings.json` `harnesses[]` still read through
    for compatibility, and every write migrates them into `config.toml`, so
    removed definitions cannot resurface.
  - Writes refuse to touch a `config.toml` that does not parse, preserve all
    unrelated keys and sections, and keep user-written argument versions
    (for example `@openma/pi-acp@beta`) exactly as written.
  - Part of openma-ai/openma-common#36.
- #35 (`de76d4d`) — CI only: drops the release-tag check that
  `release-tag.yml` already performs. No source or export changes.

This release commit only bumps `package.json`, the Git install pin in
`README.md`, and these notes. It does not publish to npm or move an existing
tag.

Consumer manifests and remote branches were not changed. This package release
does not certify or publish any consumer application's installer.
