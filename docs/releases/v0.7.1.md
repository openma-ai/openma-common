# Common v0.7.1

Released through the immutable Git tag `v0.7.1`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

Patch over `v0.7.0` (`f8473d1`). No exports were removed or renamed.

- #7 (`dc3baf2`) adopts the org contribution guide. `CONTRIBUTING.md` keeps an
  openma-common section with the release checklist. The pull request template
  and bug-report issue template land under `.github/`. Documentation only.
- #8 (`d986dd2`) makes `pnpm verify` pass on Windows.
  - CI keeps the Ubuntu `verify` job and adds `verify-windows` on
    `windows-latest`. Both install uv 0.12.17 and Python 3.12. Windows adds
    Git's gzip, bzip2, and OpenSSL to `PATH`, and installs XZ Utils 5.8.4
    after checking the zip checksum.
  - uvx virtual environments use `bin/python` on POSIX and `Scripts\python.exe`
    on Windows. Console entry points resolve `.exe`, `.cmd`, and `.bat`
    launchers.
  - npm installs on Windows go through `cmd.exe`, because `npm` is a `.cmd`
    shim that `CreateProcess` will not start.
  - Installer child processes also receive the Windows path, profile, and temp
    variables those tools need. Work tokens and model credentials stay out.
  - Publishing a finished install treats Windows `EPERM` or `EBUSY` as success
    when the destination directory already exists, and does not delete a
    staging directory that is already the published tree.
  - Tests and product extraction build archives with the `tar` package. They
    do not shell out to system `tar`.

`dist/` for the artifact helpers was updated in #8. This release commit only
bumps `package.json`, the Git install pin in `README.md`, and these notes.

Consumer manifests and remote branches were not changed. This package release
does not certify or publish any consumer application's installer.
