# Common v0.11.1

Patch release for ACP transcript fidelity and stable shared chat presentation.

- Support standard ACP v1 `compaction_update` and `compaction_summary_chunk` as
  a single ID-addressed timeline entity. Preserve first receipt order, unknown
  status values and summary blocks; apply append/replacement/null patch semantics.
- Add a dedicated compaction renderer slot. Active compaction does not fabricate
  a thought/tool event or duplicate the ordinary live waiting fallback.
- Preserve steering-input annotations and attachments through chat projection.
- Keep injected steering inputs outside activity folds and share one process
  header across sections of the same turn.
- Keep live and settled turn DOM stable; expose opt-in completion collapse.
- Expose a scroll-anchor hook and virtualized turn navigation for host clients.
- Require ACP SDK ^1.9.0 so standard compaction capabilities and notifications
  survive SDK validation. Hosts should advertise `session.compaction` only when
  they implement the dedicated rendering slot and replay support.

No AIR client identity or title-based compaction detection is required. This
release does not change the authoritative ACP prompt completion boundary.
