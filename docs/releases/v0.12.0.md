# Common v0.12.0

Released through the immutable Git tag `v0.12.0`. The tag runs
`release-tag.yml`, which publishes `@openma/common@0.12.0` to npm with trusted
publishing and provenance.

## Changes

Minor over `v0.11.1`. Shared composer chrome for chat-ui hosts
([#56](https://github.com/openma-ai/openma-common/pull/56)).

### Chat UI — ComposerShell (`@openma/common/chat-ui`)

- Export `ComposerShell` and `ComposerToolbar` from `@openma/common/chat-ui`.
- Own `start` | `end` flex toolbar topology plus CSS token hooks; hosts inject
  attach / chips / agent picker / mic / send via slots.
- Document tokens and Clash / Backchat adoption in
  [docs/chat-ui-composer-shell.md](../chat-ui-composer-shell.md).
- Keep `createComposerDraftStore`, `agentChatDensityAttributes`, and
  `AgentChatView` unchanged.

Consumers (Clash, Backchat) should move to `^0.12.0` or the git pin
`github:openma-ai/openma-common#v0.12.0` after this publish.
