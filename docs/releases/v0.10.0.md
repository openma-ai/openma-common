# Common v0.10.0

Released through the immutable Git tag `v0.10.0`. The tag runs
`release-tag.yml`, which publishes `@openma/common@0.10.0` to npm with trusted
publishing and provenance.

## Changes

Minor over `v0.9.2` (`6288c0a`). Lands the turn / work-item state machine
stack (#41) together with the Backchat GUI fixes built on it.

### Session events

- Incremental turn projector: `createTurnProjector()` applies one event at a
  time and returns structurally shared snapshots; `reduceTurn` is now a
  wrapper over it (backchat #75 #78 #79).
- `createWorkItemProjector()` is the incremental equivalent of
  `reduceWorkItems`; `reduceWorkItems` itself is linear and keeps earlier
  snapshots immutable.
- ACP content chunks and OpenMA `agent.*` chunk events are deltas. A chunk
  that repeats the open segment's tail (`"4"` after `"#104"`, a second blank
  line) is new text; the overlap heuristic used to drop it.
- Snapshot `thoughtText` / `assistantText` are running totals instead of a
  rebuild from the whole timeline: a 45k-event turn projects in about 22 ms
  with flat per-event cost.
- **Removed:** `mergeStreamingText` from `@openma/common/session-events/acp`.
  It existed only for the overlap heuristic above. No known consumer imports
  it.
- New `@openma/common/testing/stress-session` (`generateStressTurn`) for perf
  gates.

### Agent UI / chat UI

- Thought projection owns its DOM; a paused stream shows its held plain-text
  tail in place, and the text pacer integrates real elapsed time on slow
  frames.
- `AgentUITurnView`: a turn that stops streaming keeps its process strip as
  the reader left it; a collapsed strip mounts on first open
  (`defaultProcessOpen` opts in); the footer slot holds its height from the
  first frame and fades in only for a turn watched live.
- New `isTerminalTurnStatus`; `AgentUITimelineItem` gains user-input items.

### ACP harnesses

- Registry installs prune stale version directories without touching the one
  the launcher starts or one a running process uses.

### CI

- `pnpm test:perf` (turn projector growth / time / heap budgets) runs in the
  fast `verify` job.

This release commit bumps `package.json`, the install pin in `README.md`, and
adds these notes.
