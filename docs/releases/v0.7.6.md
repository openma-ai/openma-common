# Common v0.7.6

Released through the immutable Git tag `v0.7.6`. The package remains private to
npm by design; Git installs use committed `dist/` and need no build lifecycle.

## Changes

Patch over `v0.7.5` (`d7d7057`). No exports were removed or renamed.

- Process / worked-for disclosure triggers (`ChatReasoningTrigger` with
  `showIcon={false}`) no longer paint a bubble chip. They default to a full-width,
  transparent row with a light foreground hover wash, matching the intent of
  downstream host overrides without `!important`.
- Standalone thought/reasoning chips keep an optional bubble surface via
  `chat-reasoning-trigger--chip` when `showIcon` is enabled.

This release commit only bumps `package.json`, the Git install pin in
`README.md`, and these notes.
