# Common v0.7.9

Patch over `v0.7.8`. No exports were removed.

## Changes

- ACP harness installer records the **resolved installed version** in
  `registry/<id>/install.json` and returns it on `InstallResult.version`. Versioned
  install directories no longer use `v_unknown_*`; npm installs resolve a concrete
  version first (via `npmRegistryUrls`, not a hard-coded registry host).
- New `readAcpHarnessInstallState` API (re-exported from
  `@openma/common/acp-harnesses/installer`) reports installed version, latest
  version, and `updateAvailable` only when both versions are known and latest is
  strictly newer. `pi-acp` / `dsh-acp` latest comes from npm; other registry
  harnesses use the ACP registry snapshot version.
- Legacy `v_unknown_*` installs remain readable via installed `package.json`.
- `AcpAgentSetupService` uses the shared install-state helper for managed update
  detection.

This release commit bumps `package.json`, the Git install pin in `README.md`,
and these notes.
